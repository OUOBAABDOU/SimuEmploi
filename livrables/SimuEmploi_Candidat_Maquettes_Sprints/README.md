# SimuEmploi — dossier candidat pour cinq développeurs

**20 novembre 2026.** Conception d'un produit neuf : candidats en premier, backend Python/FastAPI, modules séparés puis extraction progressive en microservices. Ce kit contient spécifications et maquettes ; il n'est pas une application installable.

Commencer par [l'index candidat](docs/candidat/README.md), puis [les écrans](docs/candidat/01_MAQUETTES_ET_PARCOURS.md), [les huit sprints et quarante paquets développeur](docs/candidat/02_SPRINTS_CINQ_DEVELOPPEURS.md) et [les modules/contrats](docs/candidat/03_MODULES_ET_CONTRATS.md).

Les captures figurent dans `docs/candidat/visuels/`. `maquettes/simuemploi-candidat.fragment.html` est une copie modifiable de la proposition interactive présentée dans le chat. C'est un fragment de conception, pas une page autonome de production. Le contexte du chat fournit le changement de variante, les icônes et les contrôles de style ; ces fonctions hôtes ne sont pas livrées comme application. Les interactions métier sont simulées et les retours sont fictifs.

Les outils de vérification présents utilisent des chemins et dépendances du poste où les contrôles ont été réalisés. Les adapter pour les exécuter ailleurs. Les résultats contrôlent les maquettes et documents, pas un backend, un compte réel ou des garanties de production.

La conception générale et les références sont incluses pour conserver les liens et le contexte. Le code du prototype original n'est pas inclus dans ce kit de construction neuve. Les sprints et leur capacité restent une proposition à estimer par l'équipe ; les maquettes restent à relire avec le porteur et les utilisateurs.
