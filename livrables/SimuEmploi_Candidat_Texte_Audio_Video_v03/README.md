# SimuEmploi — dossier candidat texte, audio et vidéo 0.3

**20 novembre 2026.** Conception pour une construction neuve avec cinq développeurs full stack, backend Python/FastAPI et modules séparés avant extraction progressive en services. Ce kit réunit maquettes et spécifications ; ce n’est pas une application installable.

Le dossier candidat comprend le parcours texte et les maquettes audio/vidéo : question par question, dialogue en direct, autorisations, prise/relecture, envoi, transcription, retours, rapport et secours texte.

Les sources modifiables sont dans `maquettes/` : fragment texte, fragment médias et interactions de conception. Les illustrations et captures sont dans `docs/candidat/illustrations/`, `visuels/` et `visuels-medias/`. Deux diagrammes médias complètent les diagrammes de conception existants.

Les fragments sont présentés dans le chat ; le contexte fournit carousel, icônes et réglages de style. Aucune identité, capture microphone/caméra, lecture de média réel, transmission ni analyse IA n’est exécutée. Les états, paroles, fichiers et retours sont fictifs. Les brouillons/choix sont conservés seulement en mémoire pendant la consultation.

Les outils utilisent certains chemins locaux et dépendances du poste de conception. Adapter les chemins pour un autre ordinateur. Ils contrôlent les maquettes et les diagrammes ; ils ne constituent pas le code applicatif à reprendre pour réaliser le service.

Les lots AM0–AM3 sont une proposition à estimer et redécouper. Leur présence ne promet pas une livraison des modalités audio/vidéo dans la capacité des sprints S0–S7. Le code du prototype original n’est pas inclus. Les références historiques sont conservées comme contexte.
